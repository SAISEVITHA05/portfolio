# Koredla Sai Sevitha | Portfolio

Personal portfolio of Koredla Sai Sevitha, B.Tech student in Artificial Intelligence and Data Science at IIIT Sri City.

**Live site:** https://portfolio-olive-six-rwr75sgban.vercel.app

## What's on the site

- About me and career objective
- Projects: Study Agent, TrueTraffic AI, Project README Agent, Portfolio Website
- Skills, education, courses and hackathon participation
- Contact links (email, LinkedIn, GitHub)
- Light and dark themes

## Built with

Plain HTML, CSS and JavaScript in a single `index.html` file. No frameworks and no build step.

## Run locally

1. Clone the repo: `git clone https://github.com/SAISEVITHA05/portfolio.git`
2. Open `index.html` in a browser.

## Deployment

The site is hosted on Vercel. Every push to the `main` branch redeploys it automatically.
